1. METHODOLOGICAL FOUNDATION & MATHEMATICAL SCOPE
-------------------------------------------------------------------------------------
- Primary Model for Explanation: XGBoost Pipeline (models/xgboost.joblib).
  * Rationale: Selected as the primary non-linear ensemble candidate to demonstrate
    how post-hoc XAI reveals complex feature relationships beyond linear scorecards.
  * Note: This is an explanatory design selection, not empirical proof that XGBoost is
    the universally superior model.
- Baseline Model for Comparison: Logistic Regression Pipeline (models/logistic_regression.joblib).
- Target Convention: Class 0 = Good / Non-Risky | Class 1 = Bad / Risky / Default.
- Output Space Formulation:
  * SHAP TreeExplainer outputs values in log-odds margin space for Class 1 (Risky).
  * Exact Mathematical Identity: P(Risky=1) = sigma(base_value + sum(phi_i)),
    where sigma(z) = 1 / (1 + exp(-z)).
  * Identity Verification: Confirmed with max reconstruction error < 1e-4 across all test rows.
  * Interpretation: A positive SHAP value strictly increases the predicted log-odds
    (and thus probability) of loan default. A negative value decreases default risk.

5. METHODOLOGICAL COMPARISON: SHAP VS. LIME
-------------------------------------------------------------------------------------
  * Theoretical Basis: SHAP relies on game-theoretic Shapley values with proven mathematical
    axioms (Efficiency, Symmetry, Additivity). LIME fits a local ridge regressor on perturbed points.
  * Consistency: SHAP guarantees that local feature contributions sum exactly to the difference
    between instance output and expected base value. LIME is an approximation that can fluctuate
    depending on perturbation sampling parameters.
  * Interpretability: LIME operates directly on human-understandable threshold rules
    (e.g., 'duration > 24.00'), making it intuitive for frontline loan officers.

6. CRITICAL ETHICAL & REGULATORY GOVERNANCE NOTICE
-------------------------------------------------------------------------------------
  1. Non-Causality: SHAP and LIME values quantify statistical associations within the trained model.
     They do NOT imply real-world causation (e.g., arbitrarily lowering loan duration will not
     guarantee financial solvency for an unstable borrower).
  2. Fairness & Compliance: Explaining a prediction does NOT prove algorithmic fairness or regulatory
     compliance (e.g., US ECOA, EU GDPR). Rather, XAI serves as an auditing instrument to detect
     unlawful disparate impact or bias on sensitive attributes (such as personal_status or foreign_worker).
