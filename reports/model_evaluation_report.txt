1. METHODOLOGY & LEAKAGE PREVENTION
--------------------------------------------------------------------------------
- Cross-Validation: 5-Fold StratifiedKFold on the 800 training observations.
- Zero-Leakage Guarantee: Scalers (StandardScaler) and Encoders (OneHotEncoder)
  were fitted strictly inside each training fold using fresh scikit-learn Pipelines.
- Held-Out Test Evaluation: The 200-sample test set was evaluated exclusively after
  fitting the final pipelines on all 800 training observations.
- Class Convention: 0 = Good / Non-Risky (Negative), 1 = Bad / Risky / Default (Positive).

4. KEY FINDINGS & MODEL SELECTION
--------------------------------------------------------------------------------
* Top Performing Model by Test ROC-AUC: Logistic Regression (ROC-AUC = 0.8040)
* Baseline Logistic Regression demonstrates competitive discrimination and establishes
  an interpretable linear benchmark.
* Ensemble models (Random Forest, XGBoost, LightGBM) capture non-linear relationships
  and interaction effects, making them prime candidates for post-hoc explanation via SHAP.
* Trade-off Observation: At the standard 0.5 classification threshold, credit models
  face a trade-off between Recall (catching defaults) and FPR (rejecting creditworthy applicants).
  In production, threshold tuning based on cost matrices is advisable.
